# Instrucciones para Hostinger

## 🚨 Problema con Hostinger

Hostinger está esperando detectar automáticamente un framework moderno (React, Vue, Next.js) pero este es un sitio estático HTML/CSS/JS tradicional.

## ✅ Solución Manual (Recomendada)

### Paso 1: NO usar Deploy Automático
- NO usar "Git Deploy" ni "Deploy de Framework"
- NO seleccionar ningún framework en el panel automático

### Paso 2: Usar File Manager Manual
1. Ir a "Hosting" → "Manage" → "File Manager"
2. Navegar a `public_html/`
3. Eliminar archivos existentes
4. Subir los archivos de frontend manualmente

### Paso 3: Subir archivos correctamente
Subir estos archivos a `public_html/`:
- `index.html` (DEBE estar en la raíz)
- `css/` (carpeta completa)
- `js/` (carpeta completa)
- `assets/` (carpeta completa)
- `IMG/` (carpeta completa)

### Paso 4: Verificar estructura
La estructura final debe ser:
```
public_html/
├── index.html
├── css/
│   └── styles.css
├── js/
│   ├── auth.js
│   ├── chatbot.js
│   └── terms.js
├── assets/
└── IMG/
```

## 🎯 Alternativa: Usar Dominio Personalizado

Si el problema persiste con el despliegue automático:

1. Comprar/configurar dominio propio en Hostinger
2. Configurar DNS para apuntar al hosting
3. Subir archivos manualmente a `public_html/` del dominio
4. Activar SSL gratuito (Let's Encrypt)

## 📝 Notas Importantes

- Este es un sitio estático HTML/CSS/JS tradicional
- No requiere framework moderno (React, Vue, etc.)
- Funciona perfectamente como estático en cualquier hosting
- El backend Express.js debe ir en un servidor separado (VPS)
